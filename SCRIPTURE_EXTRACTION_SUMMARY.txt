REGEX PATTERN MATCHING
================================================================================

The extraction script uses a comprehensive regex pattern that matches:

Bible Book Names:
- Abbreviated forms with optional periods (e.g., "1 Cor.", "Matt", "Rom.", "Heb")
- Full book names (e.g., "1 Corinthians", "Matthew", "Romans", "Hebrews")
- Numeric prefixes for numbered books (1-3 John, 1-2 Samuel, etc.)
- All 66 canonical books of the Bible

Verse Reference Patterns:
- Single verse: "John 3:16"
- Verse ranges with hyphen: "Acts 2:1-6"
- Verse ranges with comma: "Romans 5:1-3" or "Romans 5:1,3"
- Multiple chapters: Properly normalized

False Positive Avoidance:
- Requires chapter:verse format after book name
- "John Wesley" is NOT incorrectly matched as a Bible reference
- Context-aware matching prevents spurious matches

Examples of Successfully Extracted References:
- John 3:16 → normalized to: John 3:16
- 1 Cor. 13:1-3 → normalized to: 1 Corinthians 13:1-3
- Rom. 8:28 → normalized to: Romans 8:28
- Matt. 5:3-12 → normalized to: Matthew 5:3-12
- Genesis 1:31 → normalized to: Genesis 1:31
- Psalm 90:2 → normalized to: Psalms 90:2
- Eph. 4:1-6 → normalized to: Ephesians 4:1-6
